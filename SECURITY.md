# Security Policy

## Supported versions

Sentinel Local is currently a prototype. Security fixes are applied only to the latest revision on the default branch.

## Reporting a vulnerability

Please do not open a public issue containing exploit details, sensitive machine information, packet captures, credentials, or personal data.

Use GitHub's private vulnerability reporting feature when it is enabled for this repository. Include:

- The affected revision or release
- A concise description of the issue
- Reproduction steps using non-sensitive test data
- The expected security boundary
- The observed result and likely impact

Do not test against systems or networks you do not own or have explicit permission to assess.

## Prototype limitations

Remediation actions such as deletion, quarantine, firewall modification, network reset, and device restriction are intentionally simulated. Reports that depend on those actions being production-ready should be treated as feature requests unless they demonstrate a boundary bypass.
